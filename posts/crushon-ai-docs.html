Crushon.AI 避坑指南：这四个雷我替你踩过了

2026-10-17 ·约 9 分钟 ·掌柜 老郭

Crushon.AI 看着就是个"选角色聊天"的简单网站，真用起来才发现处处是细节。从角色卡导入到积分消耗、从 HTML 简介到搜索结果，这四个坑我踩了一个礼拜才摸透。

第一次打开 Crushon.AI官网 的时候我以为就是个"挑个角色开始聊"的轻量级产品——左边角色库，中间对话框，右上角模型切换，界面干干净净。结果注册完一口气开了三四个角色，聊了不到半小时就开始各种不对劲：积分没了、搜索搜不到想要的、自己做的角色卡导入后字段全空、写的 HTML 简介后半段直接消失。

花了一周才把这些坑逐个排干净，整理下来写这篇——都是真实踩过的，照着防能少走很多弯路。

坑一：HTML 简介里的标签没闭合，后半段直接消失

症状

在角色创建器里写了一大段格式化的简介，加了标题、列表、图片，预览区看着好好的。点了发布之后打开角色卡详情页，发现简介只显示到一半，后面的内容凭空消失了——连我写的背景故事和性格设定都没了。

原因

Crushon 的角色简介区域支持部分 HTML 标签（<h3>、<ul>、<blockquote> 之类），但它的 HTML 解析器不是浏览器那套容错引擎。浏览器会自动帮你补全未闭合的标签，但 Crushon 不补。只要有一个 <div> 忘了写 </div>，或者 <ul> 里的某个 <li> 没闭合，解析器就会把这个标签之后的所有内容都当成"标签内部"而吃掉——页面上自然就看不到了。

解法

写完 HTML 不要急着发布，先拉到预览区最下面看一眼：

  • 简介末尾是不是你写的最后一句话，而不是"半截列表"
  • 图片能不能正常显示（图片路径错了虽然不会吃掉内容，但会留个红叉很丑）
  • 如果用了 <div style="..."> 这种容器标签，一定成对检查开闭

我自己总结了个笨办法，或者直接翻一下Crushon.AI文档里的完整标签列表对着检查，就不会漏了。虽然土，但比发布完才发现后半段没了要强。

坑二：积分不会累计，Free 和 Pro/Ultra 模型消耗逻辑完全不同

症状

注册当天先切 Free 模型聊了一下午，第二天升级了 Standard 套餐想试试 Pro 模型，发了十几条消息积分突然从 2000 掉到 1870。我当时以为是系统 bug，因为 Free 模型不是说免费吗？后来才反应过来——Free 模型免费是在"你选的模型是 Free"的前提下，一旦切到 Pro 或 Ultra，每发一条消息都扣积分，不管这条消息发得有多短。

更坑的是月底那天，我还剩 400 多积分想着留到下月继续用，结果一觉醒来积分直接清零——原来积分是"每月刷新，用完清零，累计不结转"的逻辑。

原因

Crushon 的积分消耗模型很直接：

  • Free 模型池里的所有模型，不限次数不消耗积分——这部分是真免费
  • Pro 模型每条消息 3~5 积分，Ultra 模型每条 10~15 积分，只有发消息这个动作消耗积分
  • 换声音、切模型、浏览角色库、甚至创建和编辑角色——这些都不消耗

积分每月重置到套餐额度，当月没花完的直接清零。这个设计本身没问题，但新用户特别容易忽略"不累计"这条，以为像手机流量一样能攒。

解法

三个建议：

第一，先把 Free 模型用熟再切 Pro。Free 模型虽然上下文只有 4K 左右，但日常聊天和轻度角色扮演完全够用，等你确定自己喜欢这个平台、知道哪个 Pro 模型适合你，再升级不迟。

第二，别频繁切模型。每条消息切一次的话积分消耗会很快，而且不同模型的回复风格差别很大，同一角色用不同模型聊出来的体验可能完全不一样——选一个固定用反而省积分。

第三，月底前把积分花完。当月剩多少都清掉，不如在最后两天把 Ultra 模型开出来爽几把。

坑三：搜索结果为零，其实是内容安全级别挡住了

症状

在角色库搜了好几个关键词——"赛博朋克 程序员"、"青梅竹马 护士"——结果都是空。我以为自己关键词写错了，换英文搜、换更通用的词搜，还是搜不到。但明明在分类页面里能刷到类似设定的角色，就是搜索不到。

原因

Crushon 有个内容安全级别设置，默认情况下 NSFW（成人向）角色对未解锁用户完全隐藏。如果你的搜索词刚好匹配的主要是 NSFW 角色，而你账号的内容安全级别还在"SFW Only"或默认值，搜索结果就是空的——不是没这个角色，是系统不让你看。

解法

打开账号设置，找到内容安全级别选项，调到"All Content"或者你能接受的范围。调完之后再搜一遍，刚才还搜不到的角色一下就冒出来了。

另外一个辅助技巧：先从分类页面进去，在分类内部搜而不是全站搜。分类内部的搜索结果更聚焦，不会混进来不相关的角色——比如在 "AI Roleplay" 分类里搜 "时空旅行"，出来的都是剧情向的，不会混入日常聊天的角色。

坑四：角色卡导入后字段全空，PNG 只是张头像图

症状

从 Discord 服务器下载了一个看起来很不错的角色卡 PNG，兴冲冲拖进角色创建器——结果创建器里所有字段都是空的：Name、Personality、Backstory、First Message 一个都没填充，只有头像显示正常。我以为是上传姿势不对，换了浏览器、换了拖拽方式，还是一样。

原因

PNG 不一定是角色卡。角色卡 PNG 的标准是：图片像素层存头像，base64 编码层存在图片文件的元数据里存角色设定。但很多网站下载的 PNG 只是单纯的图片文件——没有编码层，拖进创建器当然什么都读不到。

还有另一种情况：你拿到的是其他平台的角色卡，字段结构和 Crushon 的标准字段不完全匹配。Crushon 只认标准字段（Name、Avatar、Personality、Backstory、First Message 等），非标准字段会被静默忽略，导入后可能缺个性格描述或者开场白。

解法

导入前先确认文件来源：

  • 从 SillyTavern、Janitor.AI、Character.AI 导出的 PNG 基本是标准格式，可以放心导入
  • 从社区下载的，最好看一下发布者的说明——有没有标注是"Character Card"
  • 如果你拿到的只是一张普通头像图，放弃导入，直接手动创建吧

导入之后一定要逐项检查字段——自动填充只是起点，缺了的手动补。有些创作者的角色卡写得非常细致，性格描述、背景故事、说话风格都填了，导入后只需要微调就能用；有些只填了名字和头像，那跟自己建一个也没差。

防坑清单

最后把这几个坑浓缩成几条速查，下次打开 Crushon 之前扫一眼：

  1. HTML 简介写完一定检查标签闭合，预览区看到半截内容就知道哪里漏了
  2. 积分每月清零不累计，月底前记得花完，平时先用 Free 模型
  3. 搜索为空先查内容安全级别，别盲猜关键词
  4. 导入角色卡前确认 PNG 是不是真的带编码层的角色卡，普通图片导不进来
  5. 频繁切模型费积分也聊不好，选一个固定用反而体验更好

踩完这些坑之后，Crushon.AI 其实相当省心——800 万角色随便挑，自建角色的自由度也够，积分价格对轻度用户来说完全能接受。只是别像我一样一上来就急着玩，先花十分钟把基本规则摸清楚，能省很多无谓的浪费。

这套资料我平时查细节时会翻，整理得很全。国内访问卡壳的话可以换源——GitHub、Gitee、GitCode 三个仓库同步维护，目录结构一模一样。
