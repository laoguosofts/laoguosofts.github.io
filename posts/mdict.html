MDict 到底值不值得装？快问快答 9 组

2026-10-17 ·约 8 分钟 ·掌柜 老郭

从定位、安装、分组管理、版本兼容、自制词典到社区生态，九个高频问题一次性说清 MDict 这款老牌电子词典阅读器到底怎么用。

整理一篇关于 MDict 的快问快答——身边总有朋友问起它，问题大同小异，索性一并答复。

MDict 是什么？和欧路、词根词缀词典有什么不一样？

一句话：MDict 是一个纯本地离线的词典阅读器，它本身不附带任何词典内容，但能读取一种叫 mdx 的开源词典格式——它的官网上也有格式说明，网上有海量第三方制作的词典可以装进它。

和欧路词典那种「软件+内置词典+在线词库」的商业模式完全不同。MDict 的定位是「阅读器」，生态里词典由社区用户自己制作、自己分享，用户想装什么词典就装什么，没有付费墙、没有广告、没有联网强制。PC 版支持 Windows，Android 版仍在维护，iOS 用户更推荐 DictTango。如果你只需要一两本主流英语词典、愿意用现成的，欧路更省心；如果你想自由拼装几十上百本专业词典（医学、法律、计算机、小语种），MDict 才是归宿。

谁最需要装 MDict？

两类人最该用它。

第一类是语言学习者和翻译从业者——同时查五六本词典对比释义是家常便饭，MDict 的分组联合模式让这件事一秒完成，比逐本切换效率高太多。第二类是有专业术语需求的人——医学、法律、计算机、金融这些领域的专业词典，欧路、词根词缀词典几乎没有完整覆盖，而 MDict 社区里转码出来的专业词典数量惊人，从 ICD 医学编码到 ACM 计算机术语都有现成的。

反过来说，如果你平时只用牛津或朗文一本词典查日常单词、对离线没要求，MDict 的折腾成本（找词典、装词典、管分组）可能超过它的收益——欧路直接内置牛津高阶，拿来就用。

怎么装？去哪里拿安装包？

PC 版直接拿官方发布的 2.0.12，Android 版找 v2.3.7——这两个版本是目前社区公认的稳定版，新格式的 mdx 2.x 词典都能完整读取。iOS 原版长期停更，装了也是白装，直接换 DictTango for iOS，同样能读 mdx 格式。安装包的话，从官方下载拿就行，装完是个空壳，词典得自己装。

装完是空的？词典从哪里找？

社区。MDict 生态里词典的制作和分享几乎完全靠社区驱动，最主要的集散地叫 FreeMdict Forum，还有一个历史更久的中文社区 PDAWIKI，2005 年就开始运营了。FreeMdict 上的精品词典数量多、更新快，标注「精装版」「重生版」「美化版」的几乎都是 HTML + CSS 做的精排版，双栏、词性标签、例句块做得非常专业。PDAWIKI 虽然活跃度低，但有很多 FreeMdict 找不到的早期转码词典和小语种词典，值得专门逛一圈。

装词典的动作很简单：下载好 mdx 文件（有的还带 mdd 发音包和 css 样式表），MDict 里点「导入词典」指向文件就行，PC 版甚至直接双击 mdx 就能加载。

装了几十本词典之后怎么管理？分组怎么用？

分组功能是 MDict 里被低估的核心特性——装 50 本以上词典之后，不分包管理等于灾难。

分组有两种模式。默认的独立模式里，每个分组只是把词典按标签归类，你点哪本查哪本，只是不用在一大片"所有词典"里翻。联合模式更有用：切换到联合模式后，输入一个单词会同时在分组里所有词典查，结果并排显示——比如建一个"英语进阶"分组塞进韦氏、美国传统、词源词典三本，查一个词就能同时看到三套解释，对比着学效率翻倍。

分组可以按语言分、按使用频率分、按场景分（论文写作组、翻译工作组、备考专用组），同一本词典可以同时属于多个分组，创建分组本身不占空间。Android 版的分组管理界面比 PC 版简化一些，但核心功能一致。

有什么坑？装了词典打不开怎么办？

最常见的坑叫版本兼容。MDict 从 2007 年至今经历了多次格式升级，目前主流的有 mdx 1.x 和 mdx 2.x 两种格式。老版本的 MDict（比如 PC 1.3 RC4、Android v2.2）能读旧格式但读不了新格式——典型症状是词典封面能显示但词条内容全是空白。

怎么判断？FreeMdict 上 2018 年后发布的词典几乎都是 mdx 2.x，发帖人通常会注明"需要 MDict 2.0 以上版本"。所以最稳妥的做法是：直接装 PC 2.0.12 或 Android 2.3.7，两个版本可以和老版本共存，装一个新版就能通吃新旧格式的词典。

想自己做词典？难不难？

入门不难，做精品难。

最简单的方式是用 mtxt 格式写词条（就是带排版标记的纯文本），然后用 MDXBuilder 4.0 编译成 mdx。mtxt 能满足"能用"的需求，但要做精品词典（像牛津高阶那样的双栏排版、词性标签、颜色区分义项），就得用 HTML + CSS 来写词条——每条词条就是一段完整的 HTML，CSS 里定义 .headword、.phonetic、.pos、.senses、.examples 这些类，编译出来的词典在 MDict 里打开时会自动加载 CSS 应用样式，想深入了解 HTML 精排的细节，可以翻一下mdict文档里对应的章节。

不过 HTML 格式有几个硬伤要注意：MDict 内部渲染引擎不是完整浏览器内核，只支持 HTML 4.01 + CSS 2.1 的子集，不支持 flexbox、grid、HTML5 <video>；音标必须用支持 IPA 扩展字符的字体（Doulos SIL、Charis SIL、Noto Sans IPA 等），否则特殊符号会显示成方块；所有图片、音频资源必须打包进 mdd，用 resource:/// 前缀引用，不能依赖在线资源。

值得长期用吗？和同类比怎么样？

离线、自由、无付费墙这三个特点让 MDict 在电子词典这个品类里几乎没有竞品。欧路词典做得好的地方是内置词典、云同步、划词翻译，但它是封闭的——你想装自己找到的 mdx 词典？不行。词根词缀词典主打词根词缀学习，但它词典数量少、格式封闭。DictTango 是 MDict 的现代替代品，引擎更统一、支持 mdx 1.x 和 2.x 不分版本，跨平台做得更好，但社区生态还没 MDict 成熟。

长期来看，MDict 的社区生态是它最大的护城河——十年积累下来的词典制作教程、转码词典、精品美化词典，其他平台都没有。

最后一句

如果你只是日常查个单词，欧路开箱即用更省事；但如果你要同时查很多专业词典、想要完全离线自由拼装的阅读体验，MDict 是这个品类里唯一真正值得花时间折腾的选择。整理 MDict 相关资料时顺手也放了三份备份，GitHub、Gitee、GitCode 都有，国内访问哪个快就用哪个。
