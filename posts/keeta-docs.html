在香港用了两个月 Keeta，终于搞懂美团出海到底在打什么仗

2026-10-17 ·约 7 分钟 ·掌柜 老郭

从一个香港租房上班族的视角，记录从 Deliveroo 转到 Keeta 的真实体验——新人券、配送速度、覆盖范围、偶尔掉链子的订单，以及一个程序员发现的 API 彩蛋。

加班到十点的那个雨夜，我第一次打开了 Keeta

三月的香港总是说变就变。那天在中环的写字楼加班到十点，走出电梯才发现外面下着大雨，台风预警挂了橙色。我站在遮檐下掏手机，Deliveroo 首页加载了半天，最后跳出一行小字："当前区域骑手不足，预计等待 45 分钟。"

45 分钟？我住九龙，平时回家走路 20 分钟，骑手比我还慢？

旁边同部门的实习生小李凑过来："哥，你用 Keeta 啊，新人注册有 300 港币礼包，配送费也低。"

我当时的反应是——Keeta 是什么？外卖 App 不就那几个吗？

从 Deliveroo 到 Keeta：门槛差了十万八千里

回家躺在床上刷 App Store，搜了半天，在Keeta官网上确认它在香港区早就上线了，赶紧去下载了一个，图标是个橙色的 K，底下一行小字"美团国际"。哦，美团出海了，我之前真没注意。

新人礼包确实狠：300 港币分成几张满减券，最高一张 80 满 100 减，还有几张免运费券。我随手点了一家常吃的日式拉面店，原价 68 港币，用了 30 减 40 的券，加配送费 5 块，最后实付 43。同样这家店在 Deliveroo 上，配送费 25，没有满减，加起来 93。

差了 50 块。对于我这种月薪三万在香港租房的人来说，一顿饭差 50，一个月下来就是两三千。

但体验不是光看价格。第一单下完，我盯着地图看骑手——从旺角到我油麻地的公寓，显示 12 分钟送达。我当时想这肯定是骗我的，Deliveroo 上同一段路从来没低于 20 分钟过。

结果 14 分钟，骑手敲门了。

两个月里踩过的坑，以及学到的事

之后两个月我基本就固定用 Keeta 了，Deliveroo 只在极少数 Keeta 商家没覆盖的时候才会打开。但也不是没出过问题，有些细节现在想起来挺有意思。

首先是覆盖范围。 我住油麻地核心区，点什么都没问题。但有一次去西贡海边的朋友家玩，打开 Keeta 发现附近商家列表是空的——整个西贡不在覆盖范围内。文档里说香港目前主要覆盖九龙和港岛核心区域，新界偏远地区和离岛还没跟上。后来我又试了 Deliveroo，那边在西贡有商家，但配送费直接冲到 40 港币。

然后是订单取消。 有一次中午点外卖，商家接单后过了 30 分钟还没出餐，一直卡在"备餐中"。我在 App 里点了联系商家，电话过去对方说后厨忙不过来，让我取消重下。我取消后新人券没返还——后来才知道新人券只能用一次，不管什么原因取消都作废。

还有骑手联系不上的时候。 有天下午骑手接单后就没动过，地图上的小图标钉在原地整整 15 分钟。我先发了应用内置消息，没回复，又点了虚拟号打电话，响了十几声没人接。最后只能找客服，客服说骑手可能手机没电了，系统会自动取消订单全额退款。等了大约 5 分钟，果然自动取消，钱也退回来了。

这些问题不是 Keeta 独有的，Deliveroo 和 Foodpanda 也都有。但 Keeta 有几个地方让我明显感觉不一样。

作为程序员，我发现了一个彩蛋

有天深夜赶项目，想查一下 Keeta 有没有 API——作为一个偶尔搞点副业做自动化的人，我第一反应是如果能把 Keeta 的订单系统对接进自己的记账脚本里，每个月的餐饮支出自动同步到 Notion，那该有多爽。

搜了一下，还真有。Keeta 有开放平台，对外提供 RESTful API，包括订单管理、菜单同步、店铺设置几个大类。官方说这套 API 是给连锁餐厅和 SaaS 服务商准备的，安全上用了企业级加密，美团技术做后台支撑。

但我注意到一个细节——keeta文档里写了个人开发者也可以申请，需要创建应用、填写用途，然后平台审核。我抱着试试看的心态注册了开发者账号，提交了一个"个人学习用途"的申请，结果第二天就过了。拿到 App ID 和 Secret Key 的那一刻，我感觉打开了一个新世界的大门。

试了一下获取历史订单的接口，参数里传了过去 7 天的时间范围，十几条订单数据就 JSON 格式返回了，字段比我想象的全：菜品明细、实付金额、骑手信息、下单时间、送达时间。我花了半小时写了个 Python 脚本，拉完数据直接转成 CSV 丢进 Notion 数据库里。

这事儿让我对美团出海的思路有了新的理解——不是简单复制国内的补贴模式，而是把国内积累的技术能力也一起打包输出了。API 文档写得很规范，OAuth 2.0 认证流程清晰，连错误码都列得明明白白。

无人机配送和充电宝，还有那些试水中的新东西

用了两个月，我还注意到几个 Keeta 正在测试的功能。一个是无人机配送，听说在香港部分区域开始试点了，订单量不大但确实有。我自己还没碰到过，但网上有人晒了视频——橙色的无人机悬停在公寓楼上，把餐盒降到阳台上。另一个是充电宝共享，Keeta 在香港的地铁站和商圈放了一批橙色的充电宝柜，凭 Keeta 账号可以免费借还。

这些小东西看着不显眼，但组合在一起就是一个完整的本地生活生态。外卖只是入口，后面跟着支付、出行、硬件……

两个月，省下了一台 Switch 的钱

回到最初那个加班雨夜——我现在想起那个场景，更多是感慨。Keeta 2023 年 8 月才在香港上线，到我开始用的时候才过了半年多。美团用了不到半年就把补贴砸进来、把商家和骑手招募到位、把 App 和 API 全套铺好，这个速度在香港本地公司里是不敢想的。

算一下账：两个月下来，用 Keeta 比 Deliveroo 平均每单省 40 港币，我总共下了大约 45 单，省了 1800 港币。再加上几笔新人券的大额减免，实际省的钱大概有 3000 港币。一台 Switch OLED 在香港卖 2899 港币。

所以某种意义上，美团帮我买了台 Switch。

这不是软文。我只是觉得，出海这件事本身挺有意思的——一家从中国内陆长起来的公司，带着自己的技术、自己的供应链、自己的打法，在另一个城市、另一个文化环境里从零开始搭一套外卖体系。两个月前我还在想 Keeta 能撑多久，现在我在想，等它覆盖到西贡和离岛的时候，我是不是该去申请个骑手兼职玩玩。

毕竟，香港的工资再高，多一份副业总是好的。对了，我写的这份文档资料同步放在了三个仓库，怕哪一天主源挂了找不到——GitHub、Gitee、GitCode，随便点哪个都能看到。
