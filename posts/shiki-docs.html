ShikiApp 上手体验——把 Shikimori 揣进安卓口袋

2026-10-17 ·约 6 分钟 ·掌柜 老郭

一个面向 Shikimori 动漫社区的原生安卓客户端，没花里胡哨的东西，就是把查条目、追新闻、管列表这几件事做扎实。

上周被朋友拉进一个俄语动漫讨论群，发现大家聊的好多新番情报我根本跟不上——什么动画化发表、CV 阵容 PV，都是在 Shikimori 上先冒出来的。之前只把它当网页标签页挂着，手机上刷网页实在费劲，就搜了搜有没有客户端，结果就撞上了 ShikiApp——它是 Shikimori 官方的安卓客户端，官网上挂着所有渠道的入口。

装起来挺简单，但包名得认准

说实话我对俄系应用商店没什么概念，RuStore 听都没听过，最后找了一圈，发现 GitHub、IzzyOnDroid、F-Droid 都有发，嫌切换渠道麻烦也可以直接从Shiki下载拿安装包。版本号 alpha-0.3.1，大约十兆出头，安卓 5.2 以上就能跑。

装的时候多看了一眼包名——org.application.shikiapp，这是官方的。现在同名盗版 APK 太多，包名对不上的话装完就是两个独立应用，数据不共享还占空间，这点别嫌麻烦，扫一眼没毛病。

第一眼：默认首页是新闻流

打开 App 直接停在 Новости（新闻）页，不是搜索也不是列表，这点有点出乎我意料。新闻流里全是 Shikimori 站点的公开资讯——动画化发表、新番 PV 公开、官方维护通知、热门话题讨论串，按时间倒序排的，最新的在最上面。

刚开始觉得这种默认首页设计有点怪，通常客户端都会把搜索或个人列表放首页。但用了两三天就发现它的好处了：每天早上下楼买咖啡的两分钟，往下滚一遍新闻流，这周有什么新番定档、哪部漫画宣布改编动画，一眼就能扫完。比我之前刷各种动漫资讯号靠谱多了，信息源直接、没有二手转述。

目录抽屉：我最喜欢的部分

搜索框适合"我知道名字、直接查"，但逛 Shikimori 更多时候是"我没目标，想按分类瞎逛"。点搜索页左上角三条横线，或者从左向右滑，就能拉出 Каталог（目录）抽屉。

抽屉里的分类我第一次看到懵了一下，全是俄文标签——Аниме、Манга、Ранобэ、Персонажи……后来去Shiki文档翻了一下对照表才弄明白：动漫、漫画、轻小说、角色、声优/人物、俱乐部、新番日历、我的列表、新闻。

最实用的两个分类是 Календарь（日历）和 Персонажи（声优/人物）。日历按星期排好本周新番开播表，追新番的人每天翻一眼就够。声优分类是反过来用的——先点进某部番的详情页，点声优标签，直接跳到这个人的专属页面，列出他/她出演过的全部作品。我看了《葬送的芙莉莲》之后好奇菲伦的声优还配过什么，就这么一路点进去，半小时就把她的主要作品摸了个遍。

进了分类页面之后，顶部有过滤和排序选项——动漫可以按类型（战斗、治愈、科幻）、状态（放送中、已完结）、评分、放送时间筛选。过滤组合起来用，能把 Shikimori 几十万条作品条目快速收窄到自己想看的范围。

登录和不登录，两套玩法

这里有个挺实在的设计：ShikiApp 不登录也能用大部分功能。搜索浏览条目、看日历、读新闻、翻角色声优——这些只读操作不需要账号，装上就用。

但要加列表、打评分、写评论、发私信、收藏角色，这些写入操作就得登录了。因为所有写入最终都是走 Shikimori 的 API 存到你那个云端账号里的，不登录就没身份，API 不认。

还有个 18+ 的边界挺微妙的——没登录的话 18+ 条目直接隐藏；登录之后需要在网页端或客户端里确认年龄才显示。这是站点侧的内容策略，不是客户端故意卡你。

我的建议是：偶尔查个条目、看看新闻流，不登录也完全够用。但想用"追番列表"这个 Shikimori 最核心的功能，花五分钟注册一个账号还是值得的，以后换手机数据直接跟着账号走，不用再折腾备份。

适合谁，不适合谁

适合的人：Shikimori 的活跃用户，或者想跟进俄语动漫圈情报但嫌网页刷着麻烦的人。这套客户端把最常用的几个操作做扎实了——查条目、追新闻、管列表，界面干净没有广告，俄文标签配对照也能快速上手。

不太适合的：完全不碰 Shikimori 的用户，或者习惯用 MyAnimeList、Bangumi 这些平台的人。客户端只对接 Shikimori，没有跨平台数据同步，换不动的话装了也是吃灰。

最后顺手提一句，这套资料在三个仓库都有备份——GitHub、Gitee、GitCode，国内访问拿不到 GitHub 的话可以换后面两个，内容一样的。
