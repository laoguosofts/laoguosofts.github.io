期末周熬夜画图，这张 cos 照的出处我找了半小时

2026-10-17 ·约 6 分钟 ·掌柜 老郭

赶作业间隙刷到一张同学传的 cosplay 照片，想知道作者是谁，搜图引擎轮番上阵无果，最后靠一个网站的数据库勾选技巧 10 秒命中——Saucenao 到底怎么用才不浪费那 60 个数据库？

期末周的走廊上总有一种诡异的安静——所有人要么在图书馆刷题，要么在宿舍赶论文。我属于后者，凌晨两点还在对着电脑改一张课程作业里的插画素材，突然想知道这张图的原作者是谁，好给人家留个言。

手机翻出来，百度搜图，结果是一堆乱七八糟的电商图和表情包。Google 反向图像搜稍微好点，但前五个结果全是转载微博号。我甚至翻到了第三页——这种感觉就像在图书馆找一本借走了但没登记的书，你知道它存在，但就是摸不到。

室友从床上翻个身嘟囔了一句：「你去 Saucenao官网 试试啊？」

原来不是搜不到，是我不会搜

我打开浏览器，输了那个传说中的网址。页面比想象中简陋——中间一个上传框，右边一排密密麻麻的数据库复选框，默认全勾着。我把图传上去，点 Search。

结果出来了，但还是乱。六个数据库命中，三个显示的是转载，两个返回 404，最后一个是个日文论坛，我看不懂。

然后我盯着右边那排复选框看了三十秒。

素材包里那个实战案例一下子撞进我脑子里——搜不到不一定是 Saucenao 没有这张图，而是你搜的数据库里没有。默认 ALL 模式搜完所有数据库，但如果你的图片来源有预期，手动勾几个常用源反而更快更准。

勾什么数据库取决于你的图

我仔细看那张 cos 照：是一个穿古风襦裙的姑娘，背景在学校操场，右下角有个小小的「半次元」logo 水印。

既然是 cos 照，那插画数据库可以先放一放。Saucenao 的数据库清单里，cosplay 区有专门的——Danbooru、Sankaku Channel，还有半次元的 Cosplay 区。我把 Pixiv Images、ArtStation 这些插画源全取消勾选，只留了四个：Danbooru + Sankaku + bcy.net Cosplay + Twitter。

再点 Search。

第一条就是命中。作者在 bcy.net 发了完整的套图，标注了 CN、摄影、后期，甚至连用的是哪台相机都写了。我盯着屏幕愣了五秒钟——就这？之前半小时瞎忙活，结果只是因为我搜了太多没用的东西。

之后发现它还有个 API

搞定那张 cos 照之后，我又把它翻出来查了几张存图。有张插画用 Pixiv 单源搜，一秒就命中了作者的主页；有张动画截图勾了 Anime + MangaDex + Madokami，立刻定位到了具体哪一集。

逛官网的时候看到注册入口。Saucenao 网页端免注册直接能用——打开就搜，搜完就关，不留痕迹。但如果你想写脚本接入，就需要一个账户拿 API Key。免费额度其实挺友好的：30 秒内 8 次，每天 200 次，个人日常完全够用。

我去翻了一下saucenao文档，发现它的 API 有个很有意思的设计——位掩码控制数据库。每个数据库有个编号，比如 Pixiv 是 3，Danbooru 是 5，想搜 Pixiv + Danbooru 就把对应的位加起来。写 Python 脚本的时候三行代码就能算出来：

dbmask = (1 << 3) | (1 << 5)

传进去就能精确搜指定的那几个库。批量跑的时候特别好用——比如我存了一整个文件夹的截图，写个脚本一夜自动搜完、生成报告，比一张张手动点快十倍。

三种用法，按需切换

Saucenao 其实有三个入口：网页端、安卓客户端、JSON API。

电脑前搜图用网页端最合适——大屏幕看结果舒服，拖拽上传方便，数据库勾选功能最全。出门通勤的时候掏手机搜，可以用安卓客户端从下载拿包安装（社区版，非官方，但界面挺简洁），相册里选一张图一秒就能进状态。批量处理就交给 API——集成到自己的工具链里，返回结构化 JSON，想怎么处理都行。

iOS 用户就比较尴尬了，直接 Safari 打开网页版凑合用。我试过一次，功能和电脑端一样完整，就是手指点那些小复选框有点费眼。

期末周之后的复盘

那次之后我养成了一个习惯：存图之前先搜一下出处，给原作者留个言——尤其是插画和 cos 这种靠热爱吃饭的人，被人找到说一句「画得真好」可能比什么都开心。

搜图这件事，关键从来不是引擎有多强大，而是你知不知道该往哪个方向搜。Saucenao 给了你六十多个入口，但它不会告诉你哪张图应该走哪个门——这个判断，得自己练。

我后来把常用的几套数据库组合存在了浏览器书签里。下次遇到 cos 照就直接点 bcy.net 那套，遇到插画就点 Pixiv + Danbooru + Twitter 那套，遇到动画截图就点 Anime + MangaDex 那套。每一次搜图都比上一次快几秒，积少成多，这就是那个网站教我的事。

这半年的资料我同步维护在 GitHub、Gitee、GitCode 三个仓库里，国内访问哪个方便就用哪个，开源的东西还是分散点好。
