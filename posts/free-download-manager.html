Free Download Manager 上手实战：浏览器集成 + BT 优先级全流程

2026-10-17 ·约 9 分钟 ·掌柜 老郭

从零开始装好 FDM，打通 Chrome/Firefox/Edge 三浏览器自动拦截，搞定 BT 种子里只下指定文件的优先级技巧，15 分钟上手。

读完这篇教程，你能把 Free Download Manager官网 的软件装到电脑上、让它接管浏览器里的所有下载、并且在 BT 种子里精准挑文件不浪费带宽。

准备：你需要什么

  • 系统：Windows 10/11、macOS 12+、Linux（Ubuntu 20.04+、Fedora 35+ 都能跑）
  • 版本：FDM 6.x 最新版（当前稳定分支）
  • 浏览器：Chrome、Firefox 或 Edge 任选其一——三浏览器的扩展安装流程都覆盖
  • 前置条件：浏览器和 FDM 桌面端都没装过旧版本（如果之前装过，建议先卸载再装，Native Messaging 注册表残留偶尔会让扩展连不上）

第一步：装 FDM 桌面端

打开 FDM 的下载页面拿到安装包。Windows 下就是常规的 .exe 安装向导，macOS 是 .dmg，Linux 提供 .deb 和 .rpm 包。安装时注意两件事：

  1. 安装路径别选系统目录（Windows 别装 C:\Program Files，macOS 别装 /Applications 根目录）——FDM 需要写配置文件，放在用户目录下少很多权限弹窗。
  2. 向导里会让你选浏览器集成——把你装的浏览器都勾上，后面省得手动再注册。

装完启动 FDM，主界面左侧栏能看到「下载」「BT」「视频」「远程」几个分区，右侧是空的任务列表，底部一条状态栏显示当前速度和磁盘空间。

第二步：浏览器扩展安装（三选一）

扩展是 FDM 体验的核心——没装扩展的话，浏览器里点下载按钮还是走浏览器自己的下载器，FDM 就只是个单独开的窗口。三个浏览器装法各有细微差异，挑你用的那个按步骤来。

Chrome

最直接的方式：打开 Chrome Web Store，搜索 "Free Download Manager official extension"，点「添加至 Chrome」。装完别以为就完了——还有一步必须做，不然扩展不会自动拦截：

  1. Chrome 地址栏输入 chrome://extensions
  2. 找到 FDM 扩展，点右上角的「详情」
  3. 找到「站点访问」这一项，把默认的「在点击时」改成「在所有网站」

这步不改的话，扩展形同虚设——和 Chrome 扩展同理，Firefox 和 Edge 也有一模一样的权限收紧问题。

Firefox

Firefox 用户在 addons.mozilla.org 搜索官方扩展（全称是「Free Download Manager official extension」，开发者是 FreeDownloadManager.ORG，注意别装错第三方同名扩展）。装完之后：

  1. about:addons 打开扩展管理
  2. FDM 扩展 → 「管理」→「访问你的数据」权限改成「在所有网站」

Firefox 有个 Chrome 没有的优势：容器隔离（Containers）。FDM 扩展在 Firefox 的每个容器里都是独立实例，如果你用容器功能隔离开不同网站的 Cookie 登录状态，这点是 Chrome 做不到的。

Edge

Edge 从 80 版本开始用和 Chrome 同一个 Chromium 内核，所以 Chrome Web Store 的扩展在 Edge 上也能直接装。三种方式任选：

  • FDM 安装向导里勾了 Edge 的话，它会自动打开 Edge Add-ons 页面
  • 手动去 Edge Add-ons 市场搜索
  • 直接在 Edge 里访问 Chrome Web Store，Edge 会弹「确认来自 Chrome Web Store」的提示

装完之后 edge://extensions → FDM 扩展 → 「扩展详细信息」→ 站点访问改成「在所有网站」。Edge 有个「效率模式」省电功能，如果发现 FDM 扩展偶尔不工作，检查一下是不是被 Edge 休眠了——把 FDM 扩展加入「永不休眠的网站」列表就行。

第三步：验证连接是否正常

装好扩展后，先别急着批量下东西，跑一次验证：

  1. 浏览器里随便找一个可下载的文件（比如某个软件的 .zip）
  2. 点下载按钮
  3. 如果 FDM 自动弹出来接管了这个下载任务 → 连接正常
  4. 如果下载还是走浏览器自己的下载器 → 回到扩展权限那一步，再检查一遍是不是改成了「在所有网站」

如果扩展图标上显示 FDM 未连接，打开 FDM 主程序 → 菜单「工具 → 浏览器集成」，里面有「重新注册 Chrome/Edge」和「注册 Firefox」两个按钮，点一下再回浏览器试。还不行的话可以去 Free Download Manager文档 的浏览器集成章节查详细排障步骤。

第四步：BT 种子里只下你要的文件

这部分是 FDM 对比其他下载器最实用的功能之一。假设你找到一个 50 集美剧合集的种子，总大小 75 GB，但你只想先看 S01 的前 5 集——FDM 可以让你精准挑文件，不浪费带宽。

添加时就选好

不管是 .torrent 文件还是磁力链接，FDM 解析完元信息后都会弹出文件选择对话框。默认是全部勾选，按这个流程操作：

  1. 点左上角「全不选」清空所有勾选
  2. 逐个勾你要的文件（也可以直接勾某一个文件夹，整个文件夹里的文件都会被选中）
  3. 右键选中的文件 → 设为「最高优先级」
  4. 确定——FDM 只会下载你勾的那些

底部会实时显示你勾选文件的总大小，心里有数不会被坑。

中途改主意随时调

如果添加时忘了选、或者下了几集想换看别的，随时可以在 FDM 主界面改：

  1. 选中正在下载的 BT 任务
  2. 切换到下方的「文件」标签页
  3. 里面列出种子里所有文件——包括你之前跳过的那些
  4. 右键某个文件 → 改优先级，或者把「跳过」改成「普通」开始下载

不用重新添加任务，改完立刻生效。

优先级到底什么意思

优先级FDM 会怎么做
跳过完全不拉这个文件的分片
低等普通及以上优先级都下完了才开始
普通默认，和其他普通文件均匀分配带宽
高优先请求这个文件的分片
最高类似插队，抢占带宽直到这些文件下完

一个实用的场景：同一个种子里，前 3 集设最高优先级、中间 5 集设普通、剩下的全部跳过。这样你可以先看前 3 集的同时，中间 5 集悄悄在后台下，完全不浪费时间。

常见卡点

卡点一：扩展装好了但浏览器还是不拦截下载

90% 的情况是忘了把扩展权限改成「在所有网站」。Chrome、Firefox、Edge 三浏览器都有这个坑，默认权限都是「在点击时」——意思是扩展只在你点它图标时才工作，平时自动不拦截。

卡点二：Edge 更新后 FDM 扩展失效

Edge 大版本更新偶尔会重置 Native Messaging 注册。打开 FDM → 工具 → 浏览器集成 → 卸载 Edge 集成 → 重新注册，搞定。

卡点三：BT 种子里跳过的文件会影响分享率

BT 社区里，分享率 = 你上传的数据量 / 种子总大小。你只下了种子的一部分，跳过去的那些不算你下载的，但算在分母里。如果在意分享率，要么尽量下完整，要么下载完成后继续做种一段时间。

进阶：定时下载计划

FDM 有一个很多人不知道的定时功能——可以设置某个时间段自动开始/暂停下载。晚上睡觉时让 FDM 跑满带宽，白天工作时间自动限速，不抢办公网络。在 FDM 主界面的「调度器」面板里设置时间窗口，配合速度限制一起用，体验会更稳。

这套资料在三个仓库都能拿到——完整的安装说明、浏览器集成排障手册、BT 高级玩法技巧，维护更新都同步在了 GitHub、Gitee 和 GitCode 上，方便随时查阅最新版本。
