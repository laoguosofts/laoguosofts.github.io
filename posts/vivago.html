VIVAGO 是什么？一篇快问快答把 AI 视频创作平台讲透

2026-10-17 ·约 7 分钟 ·掌柜 老郭

整理一份关于 VIVAGO 的快问快答——从它能做什么、怎么上手、模板有多少、Agent CLI 怎么用，到角色一致性控制和老照片动效，每个问题直接给结论。

整理一篇关于 VIVAGO 的快问快答，把这个 AI 视频创作平台最常被问到的几个问题一次说清。

VIVAGO 到底是什么？一句话能说清吗？

它的官网上有完整的功能展示和用户案例——这是一个以 AI 视频创作为核心的在线平台，把文生视频、模板快速出片、图像生成和一个叫 R1 的智能体串在一起，面向自媒体创作者、品牌营销和普通用户。它不是单一的"AI 画画"或"AI 做视频"工具，而是把创作流程——从灵感输入到最终成片——都包了进去。

平台的特色在于模板墙和 R1 Agent 的组合：模板给不想写 prompt 的用户一条快速出片通道，R1 则给愿意跟 AI 对话、要更定制化结果的用户留了多轮创作空间。两者之间还有大量中间形态，比如图生图参考图控制、Lip Sync 口型同步、老照片动效这些单点能力，可以独立用也可以串进流程里。

谁在什么场景下会用到它？

自媒体和短视频创作者是最大群体。宠物跳舞、老照片恢复成动效、二次元四宫格分镜——这些模板类效果在短视频平台有明确的流量逻辑，VIVAGO 把门槛降到了点几下的程度。品牌营销也在用，尤其是需要快速生产风格统一的系列物料、或者要把静态素材变成动态片段的场景。另外有一批用户把它当图像生成工具用，参考图控制角色一致性这一条，对做虚拟角色设定、品牌形象不同场景展示的人来说是刚需。

怎么开始用？注册和登录有哪几种方式？

想试的话先从官方下载拿安装包或直接用 Web 端。三种登录方式：邮箱验证码、Google 账号、Discord 账号。最稳的是邮箱验证码——不依赖第三方，适合长期只用一个平台的用户。Google 账号适合 Web 端和移动端都在用同一 Google 账户的人，Discord 主要面向国际用户。

这里有个容易踩的坑：三种方式登录后的账户是相互独立的。同一个邮箱的 Google 登录和邮箱验证码登录会被识别为两个不同账户，平台侧目前没有一键迁移。选好一种方式就坚持用，别来回切换。

登录后每日自动发放 100 credits，跨端互通，Web、移动端和 CLI 都用同一套积分体系。

模板墙有多少模板？更新快吗？

目前 300+ 模板，官方标注是每周更新热门效果。大致可以归到六类：宠物萌宠类（跳舞模板、夸张表情动效）、老照片回忆类（照片恢复加动效）、二次元动漫类（Quadrant 四宫格分镜、夸张表情动效）、Lip Sync 口型同步类（AI Podcast 视频、数字人播报）、特效风格化类（星织主题、赛博朋克、梦幻光效）、人物类（自拍照动效、换装预览）。

模板由官方维护更新，用户不能自建。好处是出片质量有保证、不需要自己调参数；坏处是如果有非常具体的定制需求，模板可能覆盖不到，这时候就得转向 R1 Agent 或者图像生成能力自己拼。

图像生成里的参考图到底能控制什么？

两件事：角色一致性和风格迁移。纯文生图每次生成的角色外观会飘——"穿风衣的女人"第一次金发第二次黑发，做系列内容就废了。参考图通过 feature matching 算法提取面部五官比例、发型轮廓、服装款式颜色这些特征点，锁定住，后续生成就按这个来。风格迁移同理，上传一张水彩画或动漫截图当参考，模型就把目标内容生成为那个画风。

平台支持同时上传多张参考图（正脸 + 侧脸 + 全身），角色还原度更高。最佳实践是参考图要清晰、光线均匀，提示词里仍然要写清楚"变化方向"——参考图是引导不是复制，模型在不同场景下会有自由度。过度依赖模糊图会干扰特征提取，反而不如不用。

R1 智能体是什么？和直接用模板有什么区别？

R1 是 vivago 的对话式创作 Agent。模板是"选现成的 → 填参数 → 出片"，R1 是"跟 AI 聊你想要什么 → 多轮调整 → 逐步逼近目标"。适合的是模板覆盖不到、或者你对结果有明确但难以用模板参数表达的预期的场景。

两者不冲突。很多用户先用模板快速出第一版，再用 R1 做局部调整或风格变体；也有人跳过模板直接跟 R1 从头聊起。积分消耗上模板更省，R1 多轮对话会消耗更多 credits。

vivago-agent-cli 怎么接入？适合什么场景？

这是 R1 开放的命令行接口，用来把 R1 的视频创作能力嵌入到更复杂的自动化工作流里。典型场景包括：先用另一个 Agent 自动选题、调研、写脚本，再调用 R1 生成视频；批量处理结构化输入（CSV 里一行一个视频任务）；在自己的 Agent 工作流里加一个"一键视频化"节点。

CLI 是 shell 可调用的命令行工具，外部通用 Agent（比如 AutoGPT、LangChain 自定义 Agent）把它注册成工具就能直接用。输出是标准的 stdout 或视频文件路径，方便下游继续处理。积分消耗和直接用 R1 相同。目前 CLI 的生态集成说明在VIVAGO文档里还比较早期，命令格式和认证方式可能会变。

有没有常见的坑？先说三个最容易犯的

账户切换坑：三种登录方式相互独立，同一个邮箱用 Google 登和用验证码登是两个账户，资产不互通。选定一种就别换。

验证码收不到：先查垃圾箱，等几分钟再发一次。有时效性，过期就得重发。

参考图过度依赖：模糊、过度滤镜、光线不均的图会干扰特征提取。宁可少传一张清晰的，也别堆一堆糊的。

值不值得长期用？还是只适合临时玩一下？

如果你的创作频率稳定——比如每周都要出几条短视频、或者在做系列化的视觉物料——值得长期用。模板墙的更新节奏保证了你不会因为效果过时被淘汰，R1 和 CLI 给了往上走的空间。如果只是偶尔玩一下宠物跳舞，可能几十分钟就能把大部分模板试完，剩下的就看你有没有动力去挖更深的能力了。

最后一句：VIVAGO 把 AI 视频创作的门槛压到了"点几下"，但真正能出什么片取决于你会不会把模板、参考图、R1 串起来用——它给的是工具箱，不是开箱即用的成品。三处都有完整的资料——GitHub 原版更新最快，Gitee 和 GitCode 是国内同步，访问更稳。
