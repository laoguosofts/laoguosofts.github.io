深夜赶方案那夜，BetterVia 帮我省了三小时

2026-10-17 ·约 7 分钟 ·掌柜 老郭

加班到十二点，浏览器广告弹得像过节、视频教程不能倍速、怕搜过的东西被老板同事看到——这个 Via 的增强包，一把解决了三个痛点。

周五晚上十一点半，办公室只剩我一个人，显示器的光在黑暗里扎眼得很。

手里攥着的是下周要给客户看的方案，还差一份竞品功能对比的资料。老板下午才发的需求，原话是「下周一早我要」。我已经在 Via 里泡了四个小时——查了无数个竞品官网、翻了好几篇行业分析、在 B 站和优酷上各看了一段产品经理的复盘视频，还得翻两家竞品的帮助中心去找具体参数。

结果就是，等到我要把这些零散的信息整合成文档的时候，发现浏览器里存了一堆不想让任何人看到的标签页。

同事的历史记录里有一条 B 站视频的标题太敏感，老板的共享 iPad 上周拿去开会也用了同一个 Via 账号，更别说我刚才在 Via 里搜了好几次竞品公司的全称——万一锁屏的时候被路过的保洁阿姨或者早来的实习生瞟到一眼，都够我尴尬一整天的。

Via 原生的隐私锁只能锁历史列表和书签单页，而且每次打开都要输密码，调起来麻烦得像保险箱。我不是不信任 Via，我只是需要更细粒度的东西。

就是在这个时候，我在酷安刷到了 BetterVia。

它的官网上说得很清楚——BetterVia 不是一个独立的浏览器，而是一个 Via 的增强包，通过 LSPatch 注入到 Via 进程里。换句话说，它不改变 Via 的界面、不替换你的书签和历史，只是在 Via 跑起来的时候偷偷给它装了几个原本没有的能力。安装包从官方下载拿就行，刷入 LSPatch 管理器的操作文档里有详细步骤。

我最先用上的是截屏防护。

把这个开关打开之后，Via 里所有的隐私锁覆盖页面——历史、书签、我自己标记过的几个敏感网页——系统截图会直接提示「由于安全策略禁止截屏」。这一下就解决了我最头疼的那个问题：就算我忘了锁屏幕，有人拿起手机翻两下，看到历史记录的时候想截屏存证？截不了。

BetterVia 给了三种防护模式：全局保护、仅特定页面保护、按 URL 关键词智能判断。我选了中间那个，全局保护太极端了——银行 App 登录回调的时候有时候需要截屏发给同事确认。只保护隐私锁覆盖的页面刚刚好，日常浏览完全不受影响，敏感内容又有了一道防线。

解决了隐私的事，我开始处理第二个更紧迫的问题：视频倍速。

我在 B 站和优酷上找了几段竞品产品发布会的回放，加起来将近两个小时，正常速看太浪费时间。Via 原生不提供全局视频倍速，B 站自带 2x 倍速，但优酷那段是 VIP 专属的 1.25x，我没开会员。

BetterVia 的视频缩放倍速功能是在 JavaScript 引擎层注入的——不管网站本身有没有倍速开关，只要是 HTML5 <video> 元素，长按视频就能弹出倍速选择器，预设档位从 0.5x 到 3.0x 都有，还能自定义。

我在优酷那段回放上调了 2.0x，画面正常、声音正常、进度条也不乱跳，快了整整一倍的时间。B 站那段本来就能 2x，我直接拉到 2.5x，十几分钟搞定。两个小时的内容，四十分钟看完。

这个倍速功能有个细节挺有意思，也是我后来去 BetterVia文档里翻了才弄明白的：它和 Via 的脚本白名单解除是独立的。就算脚本白名单没开，倍速也能在腾讯视频、优酷这些被 Via 原生规则跳过的站点上生效——因为倍速脚本是 BetterVia 直接注入到 Via 的渲染层的，不经过 Via 自己的脚本引擎。这个设计比我预想的要靠谱得多。

当然也有例外，DRM 加密的视频流——比如 Netflix、迪士尼+的正片——倍速改了也没用，那是浏览器层面限制，改了会解密失败。但国内主流的视频站点，公开课、B站、优酷、腾讯视频，只要是 HTML5 播放器，基本都能生效。

第三个让我惊喜的是广告拦截规则。

我之前一直困惑一个问题：为什么在 Via 里导入了 ABP 的规则库，优酷和爱奇艺的片头广告还是照放？后来才知道 Via 自己内置了一个白名单机制，优酷、爱奇艺、芒果 TV、qq.com 这四个站点上，广告拦截规则引擎会被跳过——官方说是和这些厂商有合作，具体原因没人说得清。

BetterVia 做的事情很简单：解除这个白名单。解除之后，Via 的规则引擎对所有网站——包括那四家——都正常工作。我自己又额外导入了 damengzhu/abpmerge 和乘风去广告这两个规则订阅，优酷的片头广告和视频中间插的贴片广告，一个星期下来基本没见过。

解除白名单之后还需要做一件事：在 Via 设置里开启跨站追踪阻止、关掉第三方 Cookie、把浏览器标识设成随机或自定义。这些是 Via 原生的隐私设置，BetterVia 不管，但配合起来才是完整的反追踪链路。

BetterVia 里整理了一份反追踪最佳实践清单，分了五层：Via 原生设置打底、三个白名单解除作为中间层、超级隐身模式处理敏感搜索场景、Cookie 定时清理做长期维护、最后隐私锁加截屏防护作为物理隔离。我按照这个清单调了一遍 Via 的设置，从 Cookie 跨站点关联、广告追踪器、浏览器指纹、localStorage 隔离到截屏防护，每一项都有了对应的处理。

周五那晚我把资料整理完，给竞品做了一个功能对比表，凌晨一点发给了老板。第二天早上九点，老板回了四个字：「很详细。」

那份方案最后拿下来了。但我想说的不是这个。

我想说的是，很多时候我们花时间在「解决工具本身的问题」上，而不是「解决真正的问题」。广告拦不住、倍速调不了、隐私保护太粗——这些都是工具的毛病，但我们往往会退而求其次，忍着用、凑合用。BetterVia 做的事情，就是把 Via 从一个还不错的浏览器，变成了一个真正能跟上我使用习惯的浏览器增强包。

它不是那种能让你「哇」一下的大改动，而是一堆小功能叠在一起，让你某天突然发现：哦，之前那些让我烦的小事，现在好像都没了。

这大概就是一个好工具该有的样子吧。相关资料在GitHub仓库维护着，Gitee和GitCode上各同步了一份镜像，国内网络不好的时候切过去就能拿到。
