AdAway 上手测评：我用了一周的安卓 root 广告拦截神器

2026-10-17 ·约 8 分钟 ·掌柜 老郭

刷资讯 APP 被开屏广告烦到想摔手机，我装了 AdAway。这是一款靠系统 hosts 文件拦截广告的工具，root 模式下零耗电、零进程，体验和 VPN 方案完全不一样。

为什么我会装它

前阵子刷一个资讯 APP，开屏广告 5 秒倒计时、划两屏又插一个 3 秒的。我忍了三天终于忍不了了。

之前试过 AdGuard 的 VPN 模式——确实好用，但电池掉得肉眼可见，状态栏那个 VPN 图标也一直挂着，心理上总觉得"有个东西在盯着我的流量"。Blokada 也试过，UI 比 AdGuard 差一截。后来翻论坛看到有人提 AdAway官网，说 root 模式下根本不跑进程、零额外开销，我就动心了。

说实话我之前对"hosts 文件拦截"这个概念有点模糊，总觉得是个什么 geek 黑科技。但实际用下来发现它的逻辑简单到离谱：提前告诉手机"这些广告域名别连了，直接返回给自己"，系统 DNS 解析的第一步就掐断，广告服务器连请求都收不到。

初印象：朴素到不像一个消费品 APP

从官方下载装好打开 AdAway，第一反应是——这界面真的太工程师了。

没有仪表盘，没有"今日拦截 X 个请求"的数字，没有进度条动画。主界面就是几个按钮：应用 hosts、恢复备份、更新源。下面一列 hosts 源列表，每个源前面有个开关。就这么多。

但装起来比我想象中简单。我已经刷了 Magisk v26，只要在 Magisk Manager 设置里打开 Systemless Hosts 开关、重启，然后回到 AdAway 点一下"应用"按钮，允许 root 权限，就成了。

验证生效的方式也很粗暴——浏览器输 doubleclick.net（Google 广告域名），直接显示连接失败。那一刻我是有点爽的。

实际用下来：挑三个最有体感的点说

零耗电是真的

root 模式下 AdAway 根本不跑任何常驻进程。它生成一份 hosts 文件写到 Magisk 分区，系统通过 mount bind 把这份文件当成 /system/etc/hosts 来用。仅此而已。

不跑 VPN、不占虚拟网卡、不耗电池、不占内存。用了一周，电池健康曲线完全没变化——这一点和之前用 AdGuard VPN 模式时那种"后台偷偷跑着什么"的焦虑感完全不同。hosts 文件就是一份静态文本，系统每次 DNS 解析时读一下，没有任何额外开销。

Allowlist 救了我好几个 APP

hosts 拦截的副作用就是误杀。AdAway 合并了好几个 hosts 源，总共有几万条拦截规则，难免会有某个 APP 的正常功能域名被一起拦了。

我遇到的第一个问题是 Facebook 打不开——登录后一直转圈加载不出动态。后来翻 AdAway文档 才知道 Facebook 有个 edge.mqtt.facebook.com 域名被很多 hosts 源误当成广告拦了，加进 Allowlist 就好了。

Allowlist 就是"永远放行"的域名列表，优先级高于所有 hosts 源。用起来也简单：DNS 日志里长按某个被拦的域名 → 直接加进 Allowlist，一步搞定。通配符也支持，比如 *.ads.example.com 能一次放行整个子域名族。

现在我的 Allowlist 里躺了大概 12 个域名，覆盖 Facebook、Amazon 购物、一个天气 APP。够用了。

DNS 日志排查的爽感

AdAway 内置的 DNS 日志是个排查神器。打开后它会记录所有 APP 发起的 DNS 请求，哪些被拦了、哪些放行、时间戳、来自哪个 APP，一目了然。

我有个银行 APP 每次打开都要等 5 秒白屏，开了日志一看，它在请求一个埋点域名被 hosts 拦了。加进 Allowlist 重应用 hosts，秒开。这种"精准定位 → 精准放行"的体验，比 AdGuard 那种"我帮你都拦好了别管细节"的黑盒感舒服太多。

别扭的地方：实话实说

拦截深度有限

hosts 只能拦域名。对于同一域名下同时提供正常服务和广告的场景就无能为力——比如 Facebook 自己在推广告，你总不能把 facebook.com 整个拦了。用 IP 直连的广告请求、某些 APP 自建 DNS 解析器绕过系统 hosts 的极端情况，AdAway 也搞不定。

这时候 AdGuard 的优势就体现了——它能深入 HTTPS 流量，用 CSS 选择器隐藏页面元素，还能应对广告绕过。但代价就是需要 VPN、耗电多、闭源。

UI 真的没什么好说的

就是 Android Material Design 原生风格的列表。没有主题切换、没有统计图表、没有引导动画。它确实不好看——但也不丑，就是"能用"。如果你习惯了那种"打开 APP 先给你看一张漂亮的拦截数据仪表盘"的感觉，AdAway 会让你有点落差。

Android 9+ 的 Private DNS 有点麻烦

Android 9 引入了 Private DNS（DoT），手机会用加密 DNS。hosts 文件是在 DNS 解析之前生效的，理论上应该没问题，但我遇到过一次：开了 Private DNS 后 hosts 拦截间歇性失效，关掉就正常。后来查文档才知道某些 ROM 的 Private DNS 实现会跳过系统 hosts 检查。关掉 Private DNS 是最稳的方案。

和 AdGuard、Blokada 的简单对比

AdAwayAdGuardBlokada
价格完全免费免费版有限制，Premium 订阅免费版基础功能
拦截深度域名级HTTPS 深度过滤 + 元素隐藏DNS 级
root 模式零耗电✅❌❌
开源✅ GPLv3 全开放❌ 闭源✅ GPLv3

三者不是互相替代，是服务不同人群。如果你已经 root、在意隐私信任、想折腾 hosts 源合并和规则，AdAway 是必选项。如果不想 root 但愿意花钱买最好的拦截效果，AdGuard 体验最好。Blokada 介于两者之间——开源免费，界面比 AdAway 友好，但拦截深度也有限。

适合谁、不适合谁

适合：

  • 已经 root + Magisk 的安卓用户
  • 在意电池消耗、不接受 VPN 常驻的
  • 想折腾 hosts 源合并、自定义规则的
  • 对闭源工具有隐私顾虑的

不适合：

  • 不想 root 也不想折腾的小白用户
  • 需要浏览器内深度拦截（CSS 元素隐藏）的
  • 喜欢漂亮 UI 和数据仪表盘的

写在最后

AdAway 不是那种一上来就让你惊艳的工具。它的优势藏在细节里——用一周后你会发现电池没掉、状态栏没有 VPN 图标、hosts 文件干干净净摆在 /system/etc/hosts 里、想调整规则随时随地。

那种"简单、透明、给我最大控制权"的感觉，用久了真的回不去。

如果你也被安卓 APP 的广告烦到了、又刚好 root 了，试试 AdAway 吧。

Hosts 源合并、通配符规则、DNS 日志排查、Tasker 自动化——AdAway 的玩法远不止基础拦截那点事。关于它的完整用法我也整理了一份资料，源码和文档在 GitHub 上维护，Gitee 和 GitCode 也做了镜像方便国内用户访问。
