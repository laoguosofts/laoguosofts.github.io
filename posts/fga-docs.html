FGA 挂机半年才挖到的隐藏开关——助战兜底、换人编码、停止条件全中

2026-10-17 ·约 7 分钟 ·掌柜 老郭

大多数人装了 FGA 只会开脚本跑轮数，其实它藏着好几组冷门设置——助战逐层降级匹配、换人服 n 编码精确控制、停止条件优先级组合、相似度阈值微调，每一个都能让挂机效率翻倍。

你以为 FGA 就是个点一下开关然后让手机自己刷苹果的挂机神器？其实它藏着好几组"翻遍设置面板才找得到"的隐藏开关。去fga官网逛逛就知道，功能面板比你想象的深得多——我把它翻了个底朝天，花了整整半年才把这些冷门功能摸清楚。每一个都不是摆设，用对了能让挂机效率翻倍，甚至救过我好几次脚本卡死的尴尬时刻。

装完 FGA 先别急着点开关——安装包从官方下载拿比较稳，版本更新快，而且打包工具也没掺东西。

隐藏开关一：停止条件不止"跑 N 轮"，而且有优先级

绝大多数人打开停止条件面板，第一反应就是填个 Run Limit: 50，然后其他什么都不管了。但 FGA 支持的停止条件有 七八种，而且它们不是并列关系——有严格的优先级，先触发的先停。

优先级从高到低：手动停止 > AP 耗尽 > 物品栏已满 > 轮数/材料数/礼装数/试炼次数 > 首次通关。

这里最容易踩的坑是 物品栏已满自动停——它默认开着，但很多人不知道。刷活动关的时候活动道具占满了物品栏，脚本检测到物品栏满就停了，你以为是轮数到了或者苹果用完了，其实是没给物品栏留地方。我有次刷活动刷到一半突然停了，排查了半小时才发现是物品栏满这个条件先触发了。

材料数量停止也挺好用——"我就缺 300 凶骨，刷够就停"，脚本会实时扫描掉落，达到数自动收尾。但前提是你得开截图识别，而且材料识别要准，不然可能刷了半天材料数对不上还在跑。

隐藏开关二：助战兜底可以"逐层降级"，不是非此即彼

大家用 Preferred 模式找助战，找不到就卡在助战列表一直刷新，或者干脆用第一个凑数。其实 FGA 支持 两层甚至三层兜底——你可以先试最严格的条件，不行逐步放宽，实在不行才用第一个。

我日常 QP 关的配置是这样的：

  • 第一层（主模式）：满破孔明 + 万华镜礼装
  • 第二层（兜底 1）：放弃满破条件，只要是孔明就行
  • 第三层（兜底 2）：First，列表里的第一个

活动高难度 Boss 战我会换另一套：主模式找满破梅林 + NP 充能礼装，兜底 1 只从好友里选，兜底 2 直接手动暂停等我选——高难度关卡不能随便用差助战。

这个功能藏得真深，在偏好配置的高级设置里找了好久才发现。FGA 不会在界面上明说"你可以配多层兜底"，得进去翻。

隐藏开关三：换人服的 n 编码，精确指定首发换哪个替补换哪个

换人服大家都知道——战斗中把首发一个从者换出去，替补一个换进来。但 Skill Maker 里的 n 按钮 大多数人没碰过——它让你用编码精确指定换出和换入的位置。

编码规则是 n<起始位置><替补位置>，比如 n12 就是首发位置 1 换成替补位置 2。相比直接用御主技能 C（取决于换人服的默认逻辑），n 按钮灵活得多——你想换首发 3 换替补 1 都能精准控制。

构建指令序列的时候有个铁律：换人必须放在技能序列的最后。因为换完之后新从者才上场，才能放新从者的技能。正确顺序是首发从者技能 → 换人 → 替补从者技能 → 宝具。而且用了换人后三个御主技能全部进入冷却——别先换再想放御主技能，那时候已经冷却了放不出来。

隐藏开关四：相似度阈值默认 80%，调一下识别率翻倍

FGA 助战识别靠图像匹配，默认相似度阈值是 80%。但实际场景里这个数不一定合适——我手机屏裂了、助战列表滚动速度快、游戏更新了头像分辨率变了，80% 可能匹配不到；但如果调低到 70%，又可能匹配到长得像的别的从者。

经验是：匹配不到就往下调 5%，调到能稳定识别为止；匹配错了就往上调。调完记得跑一轮验证——别等到挂机了才发现助战全选歪了。

MLB（礼装满破）的相似度阈值单独有一组，默认 ~70%。万华镜满破星效的识别比较挑，这个阈值我一般调到 65%，不然经常检测不到满破礼装。

隐藏开关五：试炼之塔次数上限自动停（日服专属）

日服的试炼之塔（Ordeal Call）有每日次数限制，FGA 能自动检测次数用完就停——这个功能是日服限定的，而且藏得特别深，在停止条件的最下面一个选项，名字也不显眼。我是翻了fga文档才发现的。

国服和台服没有这个功能，因为没有试炼之塔系统。日服玩家如果在刷试炼之塔的时候没开这个条件，脚本会在次数用完后卡在战斗界面一直点，浪费时间不说还可能被系统检测。

一个提醒：别同时开太多停止条件

停止条件优先级虽然明确，但同时开太多容易晕——比如你开了轮数 50 轮、材料 300 凶骨、物品栏满、AP 耗尽，那哪个先触发脚本就停在哪个原因。如果你本来想跑 50 轮，结果 40 轮的时候物品栏先满了，脚本停了，你可能没注意到就以为是轮数到了。

建议日常 Farming 只开 轮数 + AP 耗尽 + 物品栏满 三个，活动期间再加材料数就够了。追求特定礼装的场景额外开礼装停止——掉一张就停，手动处理完再继续。

把它用透

FGA 真的不是个简单的开关式挂机工具——它的停止条件系统、助战兜底机制、换人编码逻辑，每一块都比表面看起来深得多。我把这些冷门开关都摸清楚之后，挂机脚本几乎没再出过问题：助战不会乱选、停止时机不会乱停、换人位置不会搞错。

写这篇的时候回头查了下官方文档——助战系统、技能制作器、配置微调每个分组都有详细说明，找不到功能先去翻一遍，比瞎试半天强。

日常挂机、活动刷本、追求特定礼装——每个场景的配置方式都不一样，别套模板。花一个晚上把这些隐藏开关摸一遍，比你刷一百轮 QP 关省的那点苹果更值。整理好的完整资料我同步到了三个仓库——GitHub 主力更新、Gitee 国内镜像、GitCode 兜底备份，哪个能上就上哪个。
