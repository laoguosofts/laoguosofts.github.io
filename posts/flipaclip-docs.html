用 FlipaClip 从零做出第一支逐帧动画：五步走通创作流程

2026-10-17 ·约 9 分钟 ·掌柜 老郭

从新建工程到导出成片，跟着这份实战教程把 FlipaClip 的核心工具串起来，绕开新手最容易卡壳的几个坑。

读完这篇教程，你能用 FlipaClip 独立完成一支 3~5 秒的逐帧动画短片，知道在 Classic 和 Studio 两个布局之间怎么切换、怎么用拉伸代替复制粘贴，以及遇到画错帧时如何不慌不忙地撤销回来。

准备：在什么设备上跑、装哪个版本

FlipaClip 的官网列出了两大运行平台——移动端（Android / iOS） 和 桌面端（Windows / macOS）。移动端靠手指或触控笔作画，适合随时随地摸鱼画草图；桌面端配鼠标或数位板，时间线操作效率更高，适合做中长片。两个平台的工程文件互相兼容，手机上画到一半传去电脑接着编没问题。

版本上直接装最新稳定版就行。新版本把撤销系统重做了，删帧、删图层都能撤回来，这一条对新手极其重要——旧版做坏一帧可能要重画半小时，新版大胆试错就好。

安装包从官方下载拿最稳，不要去乱七八糟的下载站碰破解版。FlipaClip 的免费版已经覆盖了绝大部分个人创作需求，订阅版只是解锁了自定义画布尺寸、高级混色模式和云同步这些进阶功能，刚上手完全不急着开。

第一步：新建工程，把两个关键设置想清楚

打开应用，首页点创建按钮，弹出的面板里项目名称默认是 Untitled Project，当场改掉——工程多了之后全靠名字辨认，别省这几秒钟。

真正值得停下来想一下的是 帧率（FPS） 和 画布尺寸。帧率决定一秒钟画多少帧：8 FPS 是卡通感常用值，动作足够明显又不会画得太累；12 到 15 FPS 适合流畅度要求高的短片；24 FPS 接近电影级，但画起来工作量翻倍。画布尺寸跟着你的发布渠道走：发抖音、小红书就选竖屏 9:16 预设；投 B 站或 YouTube 就选横屏 16:9。免费版画布是固定预设，订阅版才能自定义到 1920×1920。

背景色默认白色就行，后期导出 GIF 或 PNG 序列时还能另行勾选透明背景，现在不用纠结。

点确认进入舞台后，花十秒做个确认清单：顶部栏显示的是你改好的工程名、底部迷你时间线里有一个默认层、左下画笔工具被选中且颜色符合预期。随手画一笔再按撤销，验证输入响应正常——这步省不了，触屏笔没压感或鼠标没连上的时候早点发现比画到一半才察觉强。

第二步：Classic 布局里画帧，Studio 布局里排时间

FlipaClip 有两个布局——Classic 和 Studio，新手最容易犯的错误是从头到尾只在一个布局里死磕。实际上两个布局的分工很明确：Classic 负责画，Studio 负责编。

Classic 布局 是作画界面：画笔、橡皮、填充、取色器都在侧边栏，底部是迷你时间线（只显示当前层的帧缩略图）。画每一帧就是在这里完成的：新增一空白帧 → 画 → 再新增 → 再画。默认每新帧会自动复制上一帧的内容作为底图，这叫「洋葱皮」功能，让你能看到前后帧的半透明叠加，保证动作连贯。洋葱皮的层数和透明度在设置里可以调，一般开前后各 1~2 层就够了，太多反而眼花。

画了五六帧之后，切到 Studio 布局——导航栏上有个布局切换按钮，或者在移动端用双指拖拽手势。Studio 把时间线拉满整个下半屏，每一绘图层占一行横向排列，音频轨也在同一个视图里。你能看到完整的工程时间轴，这时候做的是编排：把帧拖远一点让某张画多停几拍、选中一串帧打组然后整体循环、拖动整个层的内容对齐到新的时间点。

两个布局的数据完全共用，怎么切都不丢东西。典型的工作流是 Classic 里画几帧 → 切 Studio 排一下时间节奏 → 回 Classic 补画下一段。别在 Studio 里硬画——画笔工具在这个布局下操作手感远不如 Classic，这是无数新手踩过的坑。

第三步：用拉伸代替复制粘贴，让画面停住或循环

新手做的最蠢的事情之一，是想让一张静态画面停留三秒时，复制粘贴同一帧几十次。工程里堆满重复帧之后，想改停留时长还得删半天，改到一半手滑全选删没了直接崩溃。

新版给了两个结构化工具，彻底替代复制粘贴的老路子：

拖边缘拉伸单帧——在 Studio 时间线上抓住帧方块的右边缘，横向拖到你想要的长度。比如 12 FPS 下拖出 36 个格子就是停留 3 秒。视觉效果和复制粘贴一模一样，但工程里只有一份数据，文件更小，改时长只需要重新拉一下边缘。

多帧打组再拉伸——一段动作要循环多次（比如角色连续挥手四轮），按住第一帧开始滑选把这段动作全选中，执行打组（Group），然后拉伸这个组方块的边缘。组内的内容会自动循环铺满你拉出的时长。想改循环次数？重新拉组边缘就行，组内每一帧的画作都不用动。

两种场景的判断很简单：单张静态画面停留用拉伸单帧，一段动作重复播放用打组后拉伸。拉伸和分组只作用于画面帧，音频轨独立存在——画面停留时间变长后记得回时间线检查音频落点还对不对，别出现画面都结束了背景音乐还在响的尴尬。

第四步：画错了怎么办——新版撤销系统的正确用法

逐帧动画里最怕手滑。旧版有两类操作一旦做了就回不去：删帧、删图层。无数新手因为误删一帧而重画半小时。

新版把撤销系统重做了，后来去FlipaClip文档翻了一下才看到官方原话是「几乎所有操作都能走回头路」。你在第 5 帧按下撤销，撤掉的可能是刚才在第 12 层做的改动——撤销是跨整个工程按发生顺序生效的，不是「只撤当前帧」。连删帧、删层这种破坏性操作也能原样恢复。重做（Redo）同样可用，犹豫的时候可以来回对比。

这让实验性画法的成本变得极低：想试一个夸张的动作节奏，删几帧重排，不满意一路撤回去就是。大胆画错在这里不是事故，只是多一步撤销。

当然还是有需要留心的边角：旧图层面板路径下的删除图层操作仍是永久性的（新版时间线里的删除才是可撤销的）；个别设置项变更不在撤销覆盖范围内。保险起见，重要节点手动导出一份工程备份，花不了十秒钟。

第五步：预览、调节奏、导出成片

画完一段动画之后别急着导出，先在 Studio 布局里按播放键完整跑一遍。播放控件就在时间线上，不用来回切布局。看两个东西：动作节奏对不对（有没有哪段太快或太慢）、帧与帧之间有没有跳变（洋葱皮看着没问题不代表播放时没问题）。

节奏不对的话，回到时间线上拉伸或修剪对应帧的长度就行，不用重画。帧跳变说明那一帧的画和前后衔接不上，切回 Classic 用洋葱皮对照着补几笔。

满意了再导出。FlipaClip 支持 GIF、MP4、PNG 序列三种主流格式：发社交媒体选 MP4，要拿去别的软件二次编辑选 PNG 序列帧，想做表情包选 GIF。导出时注意勾选「透明背景」——如果你的画布背景设的是白色但动画里想让底图透出来，这个选项不勾导出来就是白底，后面抠图麻烦十倍。

新手最容易翻车的三个卡点

卡点一：画布太小画到一半发现比例不对。工程创建后画布尺寸不能改（免费版如此），只能导出后在别的软件里裁切或缩放。解决办法：新建工程前就确定好最终发布渠道，选对应的预设，别等画了 20 帧才发现画布是正方形而你需要竖屏。

卡点二：图层太多时间线看不过来。默认每层显示名字，多层工程里找一帧得盯着名字扫半天。右键层标签选「Set as thumbnail」，层标签就直接显示这一帧的画面缩略图——比名字直观得多，想换回名字点 Rename 就行。

卡点三：音频和画面合不上。很多新手先画完所有帧再去加音频，结果发现对轨时要拉伸几十帧的画面才能卡上节拍。正确做法是在 Studio 布局里先把音频拖进音频轨，对着波形画关键帧——哪个位置是鼓点、哪个位置是重音，波形一目了然，画的时候直接对齐。

进阶一句话

走完这五步，你已经能产出合格的单条作品了。往下可以试试多图层叠加（前景、中景、背景分开画，动起来层次一下子就出来了），或者把工程搬到桌面端配数位板作画——笔触细腻度会让你惊讶手机端自己原来还能画得更好。
