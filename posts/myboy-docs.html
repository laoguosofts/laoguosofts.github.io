MyBoy 模拟器速查：9 个问题把安卓上玩 GBA 的事说透

2026-10-17 ·约 7 分钟 ·掌柜 老郭

从"它是什么"到"联机怎么连"、"存档同步"、"金手指用法"，一问一答把 MyBoy 的核心能力、付费边界、避坑点一次捋清。

整理一篇关于 MyBoy 的快问快答——Android 上最成熟的 GBA 模拟器之一，相信不少人刷到过但没摸透。下面这些问题是我把文档翻了两遍之后替读者该问的。

MyBoy 到底是什么模拟器？

MyBoy 是一款专注于 Game Boy Advance 的 Android 模拟器。它官网就主打这一台，不做多机种通吃，就把 GBA 这一台掌机仿得足够好——虚拟按键手感接近实体、画面渲染还原原版色调、连当年插在线上的联机线卡都用蓝牙或 WiFi 给仿真了。

原生支持 .gba 格式的 ROM，.gb / .gbc 的老 Game Boy 游戏它不认，那是同一开发者的另一款叫 My OldBoy! 的模拟器在管。

谁应该装它？

两类人：当年玩过 GBA 现在想怀旧翻出来 的老玩家，和 没碰过掌机但好奇"当年宝可梦绿宝石到底什么味儿" 的新玩家。

如果你只是想"在手机上玩点什么"，MyBoy 不是最合适的入口——它只跑 GBA 的 ROM，ROM 文件得自己搞到。真正想要的是"我有一堆 .gba 文件想在手机上流畅玩"，那 MyBoy 几乎是目前 Android 上的首选。

怎么装，有免费版和完整版什么区别？

直接从下载或应用商店搜 "MyBoy!" 就能下。免费版功能上是够用的，能加载 ROM、能存状态、能用金手指，但有几处硬性限制：

  • 金手指只能单条输入，不能多行批量贴
  • Google Drive 云存档同步锁掉了
  • 蓝牙 / WiFi 联机只能当客户端，不能当服务器（朋友那边如果买了完整版，他可以当服务器带你玩）

完整版是买断制，一次付费终身用。如果你只有自己一个人玩、不追求云同步，免费版完全够。想多设备同步存档、想跟朋友交换宝可梦，那完整版的钱值得花。

加载 GBA ROM 难不难？

不难，MyBoy 打开就是一个文件浏览器，导航逻辑跟 Android 自带文件管理器一样。建好 ROMs/GBA/ 这样一个目录把 .gba 文件丢进去，主界面点一下就加载。

少数人会遇到"点文件没反应"的情况，基本就三个原因：文件在加密目录（移到 /sdcard/Download/ 再试）、Android 11+ 的分区存储没授权（MyBoy 会弹出目录选择器，授权一下就行）、或者 ROM 本身坏了。大小写后缀它倒是很宽容，.gba 和 .GBA 都能认。

金手指代码怎么用，三种格式有啥区别？

MyBoy 原生支持三种主流的 GBA 金手指格式——GameShark、Action Replay、CodeBreaker。格式不一样，但功能上没区别，只是编码方式不同。同一个"无限 HP"的作弊效果，GameShark 版本是一长串，Action Replay 版本是另一长串，在 MyBoy 里选对格式、粘贴进去就行。

步骤很简单：游戏运行中按中间的 MENU 按钮，找到"作弊代码"，添加一条——填名字（比如"无限 HP"）、选格式、粘贴代码、保存启用。实时生效，不用退出重开。免费版只能单条输入，完整版可以一次性贴多行。

但要提一句，金手指有风险。某些直接改存档数据的代码（比如改宝可梦属性、一口气解锁全部内容）可能导致存档损坏。建议用之前先手动存一个 Save State 当回退点，出问题关掉金手指读档回来就行。另外代码有版本依赖性——日文版的代码在英文版 ROM 上可能完全无效。想查每个游戏对应格式的完整代码列表，可以去MyBoy 文档翻。

能不能联机，手机对手机？

能。MyBoy 用蓝牙或 WiFi 仿真了 GBA 当年的实体联机线卡，两台 Android 设备可以交换宝可梦、对战、或者一起玩合作类的游戏。

前提条件：两边的 MyBoy 都要是完整版（免费版只能当客户端，不能开服务器），而且两边用的 ROM 必须是同一个版本——同一个英文 ROM、同一个汉化 ROM，差一个字节联机线卡协议都对不上。

步骤也不复杂：一方进 MENU → 联机 → 勾选"作为服务器"，通信方式选蓝牙，保持游戏停在联机等待画面别退出；另一方进 MENU → 联机 → 扫描设备，配对连上之后两边同时进入游戏内的联机菜单就能开始了。蓝牙的有效距离大概 10 米，穿墙可能干扰。

存档会不会丢，换手机怎么办？

MyBoy 有两层存档：游戏本身的卡带存档（.sav 格式，跟当年实体卡带写的文件一样）和模拟器的 Save State（随时按一下就存的状态快照）。

完整版用户开 Google Drive 同步是最省心的方案——设置里登录 Google 账号、勾选"自动同步存档"和"自动同步状态"，之后每个游戏退出时自动上传，换手机打开同一个游戏自动从云端拉取最新的档。完全不用手动拷文件。

免费版的话，存档就存在应用私有目录里。想手动备份或迁移，可以用文件管理器（需要 root 权限或通过 Android 数据备份工具）把 MyBoy 的存档目录整体复制出来。

和同类 GBA 模拟器比，选它的理由？

Android 上能跑 GBA 的模拟器不止 MyBoy 一个，还有 John GBA、Emulator Pro 之类。MyBoy 的优势主要在三个地方：

一是专注——只做 GBA，没有别的机种要顾，渲染、按键布局、金手指、联机这些功能都打磨得比较成熟，不会有那种"通吃 N 机种但每个都马马虎虎"的感觉。

二是联机和云同步——蓝牙联机仿真做得早、做得稳；Google Drive 同步是少数几个能自动同时存游戏内存档和 Save State 的模拟器。

三是开发者在持续维护——更新节奏稳定，Android 版本兼容性跟得上。

值不值得装？

如果手里有 GBA ROM 或者准备去搞一套来玩，MyBoy 是 Android 端目前最成熟的选择。免费版先用着，觉得联机或云同步对你有用再补完整版的钱。我收集的这份资料也分别传到了 GitHub、Gitee 和 GitCode 三个 APK 仓库，国内网络下 Gitee 和 GitCode 访问会比 GitHub 顺畅不少。
