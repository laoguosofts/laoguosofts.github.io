从网页聊到任务栏——New Bing 三年迭代里，微软到底在押什么

2026-10-17 ·约 9 分钟 ·掌柜 老郭

2023 年以 GPT-4 联网搜索一炮而红，三年过去它长成了 Windows 的系统级入口。回头看每一个版本，迭代节奏里藏着微软对 AI 入口的真实野心。

现在打开 Windows 11 的任务栏，那个紫色圆形图标已经跟搜索框并排站了快两年。去它的官网扫一眼就能发现，这条演进线在官方叙事里早就埋下了伏笔。Win+C 一按，右侧三分之一屏幕弹出来，截图、调设置、跨应用对话——这套组合拳在 2023 年的人们看来简直是科幻。但如果把时间轴拉得更长一点，从 New Bing 第一次以 Bing Chat 的名义亮相算起，这三年的迭代其实是一条相当清晰的路线：从「给搜索引擎加一个聊天框」，走到「把 AI 做成操作系统的一层」。

来路：从搜索框到任务栏的三次关键转向

起点：2023 年 3 月，Bing Chat 惊艳亮相

那时候它还不叫 Copilot，就叫 Bing Chat。微软在自家 Edge 浏览器里偷偷塞了一个聊天入口，用的是比 GPT-4 更强的定制模型，主打一个「联网搜索 + 实时引用」——这在当时是独一无二的体验。别的 AI 聊到 2021 年就失忆，Bing Chat 能翻出你要查的那篇最新论文，还把来源链接列在回答里。

早期用户挤破头要进候补名单，我当时拿到的账号只敢每天凌晨爬起来用——白天服务器根本撑不住。但那时候的它还是个「附属品」：只能在 Edge 浏览器里用，最多算一个「增强版搜索」。谁能想到两年后它会直接住进操作系统里？

第一个转折点：三种对话模式与身份危机

2023 年夏天的一次预览版更新，微软给 Bing Chat 加了三种模式——创意、平衡、精确，颜色分别对应紫、蓝、绿。表面上看这是给用户多了一个选择权，实际上暴露出一个更深的问题：它到底是搜索引擎还是创作工具？

创意模式写出来的文案像模像样，但查一个精确数字它能给你编三种不同答案；精确模式事实扎实，写个邮件又干得像机器翻译。三种模式本质上是微软在两个方向之间踩的刹车——不想让它变成纯写作工具，也不想让它退化成只会搜答案的问答机。这种定位摇摆，在后来的 Copilot 时代依然能看到影子。

第二个转折点：系统级集成，23H2 里的首次亮相

想要在自己的机器上跑通这套系统级 AI 能力，下载最新版 Windows 11 安装包是最直接的路径。真正的质变发生在 2023 年底，Windows 11 23H2 更新里，Copilot 作为系统组件首次登场。这不再是浏览器里的一个侧边栏了——它直接坐在了任务栏上，Win+C 随时唤出，能感知你当前正在用的应用，能截屏幕分析，甚至能直接调 Windows API 帮你改系统设置。

从「浏览器插件」到「操作系统层」，这一步迈得比很多人想的要大。以前 AI 助手的最大问题是「用完就关」——你跟它聊完，它就消失在浏览器标签页里了。而系统级集成意味着 AI 不再是一个独立应用，它变成了跟文件管理器、控制面板一样的基础设施。你在 Word 里选中一段文字让它润色，在 VS Code 里截个报错让它排错，整个过程不需要离开当前应用。

第三个转折点：24H2 的深度融合与 26H1 的微调

2024 年的 24H2 更新里，Copilot 变得更安静但更深入了。它不再只作为侧边栏弹窗出现——搜索框直接集成了 Copilot 的能力，文件资源管理器里可以直接问文件相关的问题，甚至在开始菜单里也能看到它的身影。这时候微软的思路已经很明确了：不让你特意去找 AI，让 AI 在你需要的时候自己冒出来。

到了 2025 年 26H1 的预览版，界面上反而开始做减法——侧边栏的宽度更灵活，模式切换的按钮更隐蔽，一些高频操作被折叠进了右键菜单。从大张旗鼓的「AI 革命」到润物细无声的「AI 融入」，这又是一个信号。

迭代规律：微软一直在死磕什么

把这些版本串起来看，有几条线贯穿始终。

第一条线：多端协同的执念。 不管是网页版、Edge 侧栏、Windows 任务栏还是移动端应用，所有入口共享同一个账户和对话历史。你在电脑上聊到一半，拿起手机能接着聊，换浏览器也不丢进度。多端协同的完整配置步骤和各入口的功能差异对比，在文档里有更细致的说明。这件事看起来天经地义，但早期的 Bing Chat 其实做不到——不同入口之间的历史是割裂的。微软花了不少版本才把这条链打通，到现在新用户几乎感觉不到这个过程有过痛苦。

第二条线：OS 深度集成，而非应用层套壳。 很多竞争对手的做法是做一个独立的 AI 助手应用，让用户自己打开、自己粘贴内容过去。微软选了一条更难的路——让 Copilot 能感知操作系统级的上下文：当前聚焦的窗口、剪贴板内容、屏幕选区、系统设置状态……这条路的好处是用户不用「喂」它信息，但坏处是要跟 Windows 的更新节奏强绑定，每次加一个能力都要等下一个系统版本。

第三条线：内容安全的持续加码。 从早期的三种 Safe Search 级别，到 13-17 岁青少年模式的逐步开放，再到企业版的 EDP 数据保护和管理员白名单——微软在安全这件事上没省过版本号。甚至可以说，年龄限制和家长控制这块，是整个 Copilot 体系里更新最稳、最不需要怀疑的部分。相比之下，图片生成功能到现在还在不同区域反复开关，连接器生态也是断断续续。

而什么一直没怎么动？ 开放度。你很难把 Copilot 当成一个平台来开发——没有公开的插件市场，没有开发者 SDK，连接器生态跟另一个生态比起来几乎是空白。微软的思路很明确：入口我来做，能力我来控制，用户体验我来兜底。这条路线的好处是用户体验统一、安全可控，但代价是第三方创造力几乎被挡在了门外。

预判：照这个路线，下一步大概率走向哪里

说预判之前先声明——这是从迭代规律推的，不是官方口径。

最确定的一条：Copilot 会继续往「隐身」方向走。从 23H2 的大图标弹窗，到 24H2 的搜索框集成，再到 26H1 的界面减法，这个趋势太明显了。未来你可能再也看不到一个独立的「Copilot 入口」——AI 能力会直接织进每一个应用的每一个右键菜单、每一个选中选区的浮动工具栏里。Win+C 这种全局快捷键可能会保留作为「紧急召唤」，但日常使用场景里你甚至不会意识到自己在跟 AI 说话。

第二条：多模态输入会成为默认而非例外。截图分析现在还是一个需要点一下按钮的功能，但从版本节奏看，微软在逐步降低它的使用门槛——从手动截图粘贴，到直接框选屏幕区域，再到可能的「选中即问」。语音输入同理，从需要点开麦克风按钮，到未来可能直接对着屏幕说话就行。

第三条：企业场景的投入会继续加码。Copilot 的企业版功能（EDP 保护、管理员白名单、Azure AI 接入）更新频率比个人版更稳定，而且每次系统更新都会强化这条线。考虑到微软的主要收入来源还是企业订阅，这条优先级在短期内不太可能变。

至于哪些方向可能还会继续摇摆？图片生成的区域限制、连接器生态的开放程度、个人用户的数据自主权——这几个问题在过去三年里反复被摆出来又反复被搁置，短期内很难看到根本性的变化。

尾声

我从 Bing Chat 候补名单的时候就开始用，看着它从一个「Edge 专属聊天气泡」长成 Windows 里跟搜索框并排的基础设施。三年时间里，它的每一次大更新几乎都踩中了当时的技术节点——GPT-4 出来的时候它第一个用，系统级集成别人还在观望的时候它先上了，多端协同做了一年多才基本跑通。

但最有意思的不是它做了什么，而是它没做什么。它没有变成一个开放平台，没有让开发者随便往里塞插件，没有把自己做成一个独立于操作系统之外的超级 App。微软对它的定位从第一天起就很清楚：Copilot 是 Windows 的一层，不是 Windows 之外的另一个世界。

这个定位决定了它的天花板——也决定了它的下限。
