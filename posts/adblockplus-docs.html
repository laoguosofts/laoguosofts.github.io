手机上装 Adblock Plus，三分钟从下载到能用

2026-10-17 ·约 8 分钟 ·掌柜 老郭

新手向实战教程，覆盖 Android 和 iOS 两大平台的安装、订阅配置、拦截验证、白名单放行全流程，以及最容易翻车的三个卡点。

这篇教程看完，你就能在手机浏览器上把 Adblock Plus官网（下面简称 ABP）完整用起来——装得上、拦得住、遇到想支持的网站也知道怎么放行。

准备：先确认你的手机能用 ABP

ABP 不是所有手机浏览器都能装，先说清楚边界，省得你白折腾。

Android 端：Chrome 从 Manifest V3 迁移后不再支持内容拦截扩展，所以 Android 上想装 ABP，得用 Firefox 或 Kiwi Browser。Firefox 是主流选择，Kiwi 是 Chromium 内核但保留了扩展接口，两者都能从下载通道拿到安装包。Android 7.0 及以上系统都能跑，不用 root。

iOS 端：Safari 从 iOS 11 开始支持内容拦截器，ABP 在 App Store 有正式版，直接装就行。唯一限制是 iOS 沙盒机制，ABP 只能管 Safari 浏览器，管不了 App 内部的广告。

准备好了吗？接下来按你的平台走。

第一步：下载安装，点两次就完

Android（Firefox 路线）：

  1. 先装 Firefox——如果手机上还没有，从官方下载通道拿，国内应用商店有时候上的不是最新版；
  2. 打开 Firefox，地址栏输入扩展页面，搜索 "Adblock Plus"；
  3. 点开官方那个（图标是红底白字的 ABP logo），点"添加到 Firefox"，弹窗里再确认一次"添加"；
  4. 右上角会弹出一个小徽章说 ABP 已安装，任务完成。

Android（Kiwi 路线）：

  1. Kiwi 不在国内任何应用商店，得从官网下载 APK；
  2. 装完 Kiwi 打开，右上角三个点 → 扩展程序 → 开启"开发者模式"；
  3. 回到扩展页面的商店，搜索 Adblock Plus 安装。

iOS：

  1. 打开 App Store，搜 "Adblock Plus"，找开发者是 Eyeo GmbH 那个；
  2. 点获取，装完后系统会弹引导让你去"设置 → Safari → 内容拦截器"里把 ABP 的开关打开；
  3. 去设置把开关开了，再回 Safari 就能用了。

第二步：配置订阅，别瞎装一堆

ABP 的拦截能力几乎全靠订阅列表——你装的扩展本身只是个过滤引擎，真正决定拦什么不拦什么的是订阅。ABP 默认会根据你浏览器的语言自动装一个 EasyList 的对应变体，但只有这一个通常不够用，再补两个就很够用了。

推荐的组合是这样：

  1. EasyList（或 EasyList China）——主力广告拦截，装了就有两万多条规则覆盖横幅、弹窗、YouTube 前贴片这些主流广告。中文用户一定选带 China 后缀的变体，国内网站的广告补得更全；
  2. EasyPrivacy——反跟踪专用，不是拦广告，是切断那些藏在页面里偷偷收集你浏览数据的第三方追踪器；
  3. Fanboy Social（可选）——把网页上的 Facebook / X / LinkedIn 分享按钮整块移除，清爽很多。

打开 ABP 的设置面板，找到"过滤列表"或"订阅管理"，点"添加订阅"把上面三个勾上就行。注意别同时装 EasyList 和 Fanboy's List——两者大约 80% 规则重复，浪费算力还会叠加误伤概率。Acceptable Ads 那个默认开启的可接受广告列表，不想看任何广告就把它关掉。订阅和规则的完整配置说明可以查 adblockplus文档。

第三步：验证一下，拦得住才叫装对了

配完订阅别急着关掉，先做个快速验证，确认 ABP 真在工作：

  1. 打开任何一个你以前觉得广告多的网站——比如新闻门户、视频网站、论坛；
  2. 看横幅广告位是不是变成空白或直接消失了；
  3. 点一下 ABP 图标，弹窗里应该能看到一个"已拦截 X 条请求"的数字，X 大于 0 就说明引擎在转；
  4. 随便找个弹窗入口点一下——以前会弹广告的按钮现在应该没反应了。

如果打开 ABP 图标看到拦截数字一直是 0，八成是订阅没装成功，回到第二步检查一下过滤列表是不是都打上了勾。

第四步：白名单放行，别把你想看的站一刀切

ABP 装完之后你大概率会遇到一种情况：某个你常去的网站加载异常、功能按钮点不动、或者干脆空白一片——十有八九是 ABP 把它的某个必要脚本当成广告给拦了。这时候不要急着卸载 ABP，给这个网站加个白名单就好。

操作路径：

  1. 打开那个想放行的网站；
  2. 点浏览器工具栏上的 ABP 图标；
  3. 弹窗顶部会显示"Blocking ads on 当前域名"；
  4. 把右侧那个开关关掉——它会变成"Allowlisted on 当前域名"；
  5. 刷新页面，网站就正常了。

这个操作在 Android Firefox、Kiwi、iOS Safari 上几乎一模一样，Safari 稍微绕一点但也能找到。白名单开关关掉之后，ABP 在这个网站上的所有功能——广告拦截、反跟踪、元素隐藏——全部暂停，等价于把这个域名的过滤规则整体豁免。

还有个细节值得说：ABP 默认开启智能白名单，你把某站加进白名单之后，有效期是 7 天。7 天内每次访问都会自动续期，7 天没碰过这个站，白名单自动到期移除——等于不会让白名单无限堆积。如果你想永久放行某个站，得进设置面板手动添加白名单条目，不要靠图标开关。

最容易翻车的三个卡点

卡点一：Android 上 Chrome 装不了 ABP

这是 Manifest V3 政策导致的，不是你操作有问题。Chrome 现在只支持声明式内容拦截（有限数量规则），ABP 这种动态过滤引擎装不进去。解法就是用 Firefox 或 Kiwi，别在 Chrome 上空耗时间。

卡点二：YouTube 还是有广告

EasyList China 对 YouTube 前贴片广告的覆盖确实有限——Google 一直在改广告注入方式来绕过拦截。如果装完 ABP 发现 YouTube 广告还是跳出来，可以去 ABP 设置里找专门的 YouTube 规则订阅，或者看看社区有没有针对近期变化的临时规则。

卡点三：白名单开了忘了关

有时候为了看某个临时弹窗你开了白名单，看完忘了关，过几天发现广告怎么都回来了才反应过来。记住智能白名单是 7 天续期的——如果你每天都在逛那个站，白名单就永远不会过期。想检查当前有哪些站在白名单里，进 ABP 设置的"例外规则"面板就能看到全部条目。

进阶一句话

如果你发现某个特定网站 ABP 拦得太狠、或者某些广告就是拦不住，可以进 ABP 设置面板写自定义过滤规则——规则语法和 uBlock Origin 通用，社区里有现成的规则片段直接复制粘贴就能用。

整理好的安装包和配套文档分别上传到了 GitHub、Gitee、GitCode 三个开源仓库，方便不同网络环境下查阅和下载。
